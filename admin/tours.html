Tour manager

Build a client's 360° folder and get one link to send them.

How this works. The site is hosted as static files, so there is no server to save to. This tool edits the tour list in your browser and gives you the finished assets/data/tours.json to save over the existing one and commit.

Before adding a scene, put its panorama in assets/pano/ as two equirectangular JPEGs — <name>-4k.jpg (4096×2048) and <name>-8k.jpg (8192×4096) — plus <name>-thumb.webp. The viewer picks the tier the visitor's GPU can take. scripts/make-pano.py produces all three from one source image.

The link is the key. Anyone holding it can view that client's scenes and no others; there is no password. Treat it as unlisted, not private.
